# Notebooks

This folder contains the Python notebooks used in the PaySim fraud detection project.

## Project Notebooks

### 1. `01_data_overview.ipynb`

This notebook covers:

- Loading the PaySim dataset
- Checking dataset size and column names
- Reviewing data types
- Checking missing values
- Checking duplicate transactions
- Analysing fraud and non-fraud class distribution
- Measuring class imbalance
- Visualising the fraud distribution

### 2. `02_exploratory_data_analysis.ipynb`

This notebook covers:

- Transaction type distribution
- Transaction type counts and percentages
- Fraud cases by transaction type
- Fraud rate by transaction type
- Fraud-risk visualisations
- Business insights from transaction patterns

More notebooks will be added as the project progresses.
